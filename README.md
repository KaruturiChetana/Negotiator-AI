# Negotiator AI

An AI-powered shopping and negotiation assistant for laptops and smartphones, built with Fetch.ai Agentverse and ASI:One.

## What It Does

Negotiator AI helps shoppers:
- Compare laptop and smartphone offers.
- Evaluate specifications, price, condition, and warranty.
- Identify the cheapest and best-value options.
- Prepare polite negotiation messages.
- Suggest counteroffers while respecting a strict budget.
- Identify potential risks when buying used devices.

## Technology

- Python
- Fetch.ai uAgents
- Agent Chat Protocol
- ASI:One
- OpenAI-compatible API client
